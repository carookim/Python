데이터 결측치 처리하기 :
1) 직접 행들을 순환시켜서 try문으로 타입 변환이 안되는 에러가 난
해당 데이터들을 리스트(bad_values)에 저장하여 nan 으로 replace(bad_values,pd.NA)

# 빈 리스트에 변환 불가 값 저장
bad_values = []

# 각 값마다 float 변환 시도
for val in df['horsepower']:
    try:
        float(val)
    except Exception as e:
        bad_values.append(val)  # 에러 발생 값 저장

# 에러 난 값들을 NaN으로 대체
df['horsepower'] = df['horsepower'].replace(bad_values, pd.NA)

-> replace에서 리스트 내부의 데이터들의 어떻게 저절로 na가 되는지 에 대하여,
리스트 내부에 있는 요소들을 지정한 데이터 내부에서 찾는 기능을 가지고 있다. 중복으로 적지않아도 된다.
 - 현상수배 목록 같은 느낌

2) pd.to_numeric 으로 돌리고 에러가 난 해당데이터는 errors = 'coerce'로
숫자로 변환할 수 없는 값은 자동으로 NaN 처리 후, 기존 시리즈를 재정의

df.horsepower = pd.to_numeric(df.horsepower,errors='coerce')

3) 람다로 실수 여부를 확인, 아닌 경우에는 nan값으로 자동처리,
해당 시리즈의 각 원소에 함수를 적용, 적용된 값을 기존 시리즈에 재정의

df.horsepower = df.horsepower.apply(lambda x : x if isinstance(x,float) else pd.NA)

apply()
Series에 사용: 각 원소에 함수를 적용
DataFrame에 사용: 각 행(row) 또는 열(column)에 함수를 적용

=> 전체적으로 특정 데이터를 nan값으로 변환하는 방법은
메소드, 혹은 함수에서 제공하는 자동 처리 기능을 활용한다.
1) 순환문 + try /except + replace(결측치로 처리할 값 리스트, pd.NA)
2) pd.to_numeric(검수할 데이터,errors='coerce')
3) 람다 + apply + isinstance(x,float) else pd.NA

이렇게 NaN으로 대체된 데이터들을 어떻게 처리할지를 고민해봐야한다.

> 결측치 NaN을 삭제하지않는 경우, 유지 혹은 대체
결측치 자체가 의미가 있는 경우 - 
결측된 데이터 자체가 데이터 분석에 영향이 없는 경우 -
인공지능 학습의 경우에는 데이터별 관계성에 대한 수치와 정확성을 조금이라도 올리기위해 삭제하지않는 경우도 있다.
전체 데이터중에서 NaN값이 차지하는 비율이 높다면 삭제를 유보한다.

다른 값으로 대체하는 경우,
주로 fillna()를 사용하여
평균(.mean()), 중간값(.median()), 최빈값(.mode()), 앞뒤 데이터,혹은 임의로 0, 결과없음 등으로 대체한다.

결측치를 다른 값으로 대체하는 명령어 :

결측치를 삭제하지않고 제외하고 연산하는 명령어 : ~
df[~df.horsepower.isna()]

결측치를 다른값으로 대체하는 명령어
df['col'].fillna(df['col'].mean(), inplace=True)
df['column_name'].fillna(method='ffill', inplace=True)
df['col'].fillna(0, inplace=True)

학습 시킬 데이터 다항식으로 변환하기 :
from sklearn.preprocessing import PolynomialFeatures
poly = PolynomialFeatures(degree=2) # degree는 차수를 설정, 현재는 2차항으로 설정
x_poly_train = poly.fit_transform(x_train)
x_poly_test = poly.transform(x_test) # <- 테스트 데이터에서 transform을 사용해야되는 이유,
                                        # fit_transform은 데이터 기준으로 poly 구조를 다시 학습한다.

                                            # 학습데이터를 기준으로 테스트 데이터 구조도 맞춘다.
